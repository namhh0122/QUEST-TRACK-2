# 데스크톱 펫 계획서

## 만들 것
- 화면 오른쪽 아래 구석에 앉아서, 내가 키보드를 칠 때마다 따라 치는 펭귄 펫
- 그림은 `art/sheet.png` 한 장(2×2 네 칸)을 잘라서 씀
  - ① 왼쪽 위: 두 발 들기
  - ② 오른쪽 위: 왼발로 누르기
  - ③ 왼쪽 아래: 오른발로 누르기
  - ④ 오른쪽 아래: 졸기
- 움직임
  - 가만히 있을 때: ①
  - 키를 누를 때마다: ② → ③ → ② → ③ … 번갈아
  - 마지막 키를 누르고 0.3초 뒤: ①로 돌아감
  - 10초 동안 아무 키도 안 누르면: ④ 졸기
  - 졸다가 키를 누르면: 바로 깨서 ②부터
- 창
  - 크기는 가로세로 150점, 처음 자리는 오른쪽 아래(작업표시줄 바로 위)
  - 배경은 투명하고 테두리는 없음. 펭귄만 보임
  - 항상 맨 위에 떠 있음
  - 마우스로 끌어서 옮길 수 있음
  - 오른쪽 클릭하면 "끄기" 메뉴가 나옴
  - 작업표시줄에는 그대로 보임. 누른 횟수는 화면에 띄우지 않음

## 어디서 돌아가는지
- 내 컴퓨터: Windows 11
- 만드는 동안에는 `python pet.py` 로 실행
- 다 만들면 PyInstaller 로 묶은 `pet.exe` 하나를 더블클릭해서 실행
- 컴퓨터를 켤 때 자동으로 실행하지는 않음

## 재료
- 그림: `week-03/art/sheet.png` (1254×1254, PNG)
- Python (지금 3.15.0)
- 패키지 (설치는 0단계에서 허락을 받고 함)
  - PySide6-Essentials: 투명한 펫 창
  - pynput: 키를 눌렀는지 듣기 (몇 번 눌렀는지만 셈)
  - Pillow: 그림을 네 칸으로 자르기
  - PyInstaller: exe 로 묶기
- 만들 파일 (모두 `week-03` 안)
  - `cut.py`: 그림 자르기
  - `art/frames/` 안의 4장: 자른 그림
  - `pet.py`: 펫 프로그램
  - `.gitignore`: 묶을 때 생기는 `build/`, `dist/` 를 커밋에서 빼기

## 단계

### 0단계 · 준비
- 할 일: 패키지 4개를 설치해도 되는지 묻고, 허락하면 설치한다.
- 확인할 것
  - 패키지 4개가 모두 오류 없이 설치됐나?
  - `python -c "import PySide6, pynput, PIL"` 를 실행하면 오류 없이 끝나나?
  - (하나라도 "아니오"면 Python 3.15 가 아직 새 버전이라 그럴 수 있음. 그 자리에서 멈추고 어떻게 할지 같이 정하기)
- 커밋: 없음 (파일이 바뀌지 않음)

### 1단계 · 그림 자르기
- 할 일: `cut.py` 로 `sheet.png` 를 네 칸으로 똑같이 자르고, 펫 크기로 줄여 `art/frames/` 에 저장한다.
- 확인할 것
  - `art/frames/` 에 그림이 4장 생겼나?
  - 펭귄 바깥 배경이 투명한가? (검은색이 아닌가?)
  - 네 장을 번갈아 넘겨 볼 때 몸·얼굴·키보드가 제자리에 있나? (어긋나면 펭귄이 흔들려 보임)
  - ④의 "zzz"가 잘리지 않고 다 보이나?
- 커밋: `week-03: 펫 그림 네 칸으로 자르기`

### 2단계 · 펭귄 창 띄우기
- 할 일: `pet.py` 로 투명하고 테두리 없는 150점 창을 오른쪽 아래에 띄우고 ①을 보여 준다.
- 확인할 것
  - `python pet.py` 를 실행하면 오른쪽 아래에 ① 펭귄이 뜨나?
  - 펭귄 둘레에 검은 네모나 테두리가 없나?
  - 펭귄이 작업표시줄을 가리지 않고 바로 위에 앉아 있나?
  - 다른 창을 펭귄 위로 끌어와도 펭귄이 계속 보이나?
- 커밋: `week-03: 투명한 펭귄 창 띄우기`

### 3단계 · 끌어서 옮기기와 끄기
- 할 일: 왼쪽 버튼으로 끌면 따라오고, 오른쪽 클릭하면 "끄기" 메뉴가 나오게 한다.
- 확인할 것
  - 펭귄을 끌면 마우스를 따라 움직이나?
  - 놓은 자리에 펭귄이 그대로 머무나?
  - 오른쪽 클릭하면 "끄기" 메뉴가 나오나?
  - "끄기"를 누르면 펭귄이 사라지고, 작업 관리자에서도 사라지나?
- 커밋: `week-03: 펭귄 끌어서 옮기기, 오른쪽 클릭으로 끄기`

### 4단계 · 타자에 맞춰 움직이기
- 할 일: pynput 으로 키를 누를 때마다 ②와 ③을 번갈아 보여 주고, 0.3초 동안 안 누르면 ①로 돌아가게 한다.
- 확인할 것
  - 메모장에서 글자를 칠 때 펭귄이 ②와 ③을 번갈아 보여 주나?
  - 치기를 멈추면 금방 ①로 돌아오나?
  - 10초 동안 빠르게 쳐도 펭귄이 멈추거나 프로그램이 꺼지지 않나?
  - `pet.py` 에서 어떤 키인지 저장하거나 보내는 줄이 하나도 없나? (같이 읽어 보기)
  - `week-03` 안에 키 기록 파일이 새로 생기지 않았나?
- 커밋: `week-03: 타자 칠 때 펭귄이 따라 치기`

### 5단계 · 졸기
- 할 일: 10초 동안 아무 키도 안 누르면 ④를 보여 주고, 키를 누르면 바로 ②부터 다시 친다.
- 확인할 것
  - 키를 안 누르고 10초쯤 기다리면 ④ 졸기로 바뀌나?
  - 5초만 기다렸을 때는 아직 ①인가?
  - 졸고 있을 때 키를 하나만 눌러도 ②로 깨나?
- 커밋: `week-03: 10초 쉬면 졸기`

### 6단계 · exe 로 묶기
- 할 일: PyInstaller 로 그림까지 넣어서 `pet.exe` 하나로 묶고, `.gitignore` 에 `build/`, `dist/` 를 넣는다.
- 확인할 것
  - `dist/pet.exe` 를 더블클릭하면 펭귄이 뜨나?
  - 검은 명령 창은 안 뜨나?
  - exe 에서도 끌어서 옮기기, 따라 치기, 졸기, 끄기가 모두 되나?
  - `git status` 에 `build/`, `dist/` 가 안 보이나?
- 커밋: `week-03: pet.exe 로 묶기` (`pet.exe` 파일은 커밋하지 않음)

### 7단계 · 눈이 마우스 포인터를 따라 움직이기
- 할 일: 펭귄 눈(①②③의 파란 눈)이 마우스 포인터 쪽으로 조금 움직이게 한다. 마우스 위치는 화면에서 바로 읽고, 저장하지 않는다.
- 확인할 것
  - 마우스를 펭귄 왼쪽 위로 가져가면 두 눈이 왼쪽 위를 보나?
  - 마우스를 화면 반대쪽 끝으로 옮겨도 눈이 눈 테두리 밖으로 나가지 않나?
  - 타자를 칠 때(②③)도 눈이 마우스를 따라가나?
  - ④ 졸 때는 감은 눈이 그대로인가?
  - 눈 둘레에 하얀 얼룩이나 끊긴 테두리가 안 보이나?
- 커밋: `week-03: 눈이 마우스 포인터 따라가기`

## 하지 말 것
- 어떤 키를 눌렀는지는 저장도 전송도 하지 않고, 몇 번 눌렀는지만 센다.
- 아무것도 인터넷으로 보내지 않기
- 누른 횟수도 파일로 저장하지 않기. 프로그램을 끄면 사라짐
- 컴퓨터를 켤 때 자동으로 실행되게 하지 않기
- `week-03` 밖의 파일은 만들거나 고치지 않기
- 허락 없이 패키지를 설치하지 않기
- 한 번에 여러 단계를 하지 않기. 한 단계를 끝내고 확인하고 커밋한 뒤 다음 단계로 넘어가기
- `build/`, `dist/`, `pet.exe` 를 커밋하지 않기 (용량이 큰 파일이고, 공개 저장소임)
