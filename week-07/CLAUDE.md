# week-07 · 로그인하면 열리는 내 사이트

## 주제
- 로그인하면 열리는 내 사이트

## 이번 주 목표
- 내 작품을 먼저 만들고, 마지막에 로그인과 보관함을 붙이기

## 이번 주 규칙
- 로그인과 보관함은 오늘 붙였다.
- 기록은 Firestore 에 저장하고, 저장하는 코드는 한곳에 모아 둔다.
- 답은 한국어로 한다.

## 작품
- 플레이리스트를 만들어 언제든지 즐길 수 있는 음악 사이트 (week-07/index.html)
- 남길 것: 플레이리스트에 들어 있는 음악, 플레이리스트를 만든 사람, 플레이리스트의 별점

## 기능 표
로그인이나 데이터베이스가 있어야 되는 기능은 나중에 붙이니까 뺐다. 쉬운 것부터 어려운 것 순서.
"넣음" 칸에는 이번에 넣은 기능에 표시한다.

| 번호 | 기능 | 쓰는 사람에게 좋은 점 | 어려움 | 넣음 |
|---|---|---|---|---|
| 1 | 플레이리스트 만들기 (이름과 만든 사람 이름 적기) | 내 목록을 바로 만들고, 누가 만들었는지 한눈에 보인다. | 쉬움 | ✅ 넣었다 |
| 2 | 별점 주기 (별 1~5개 누르기) | 마음에 드는 목록을 별로 표시해 둘 수 있다. | 쉬움 | ✅ 넣었다 |
| 3 | 음악 넣고 빼기 (곡 이름·가수·소리 파일 주소) | 듣고 싶은 곡만 모아서 내 목록을 꾸밀 수 있다. | 쉬움~보통 | ✅ 일부 (곡 이름·가수만, 소리 파일 주소는 아직) |
| 4 | 새로 열어도 그대로 남기 | 닫았다 열어도 만든 목록과 별점이 그대로 있다. | 보통 | ✅ 넣었다 (Firestore 에 저장. 로그인하면 어느 기기에서나 이어서 보인다) |
| 5 | 재생·멈춤·다음 곡·이전 곡 | 목록을 순서대로 이어서 들을 수 있다. | 보통 | ✅ 넣었다 (소리 파일이 없어서, 곡 이름으로 만든 짧은 멜로디가 나온다. 마지막 곡이 끝나면 멈춘다) |
| 6 | 찾기와 정렬 (이름 검색, 별점 높은 순) | 목록이 많아져도 좋아하는 것을 빨리 찾는다. | 보통 | ✅ 넣었다 (플레이리스트 이름으로 찾기·띄어쓰기 무시, 최근 만든 순/별점 높은 순. 찾기·정렬은 저장하지 않는다) |
| 7 | 곡 순서 바꾸기 (끌어서 옮기기) | 듣고 싶은 순서대로 목록을 다시 짤 수 있다. | 보통~어려움 | ✅ 넣었다 (≡ 손잡이를 마우스·손가락으로 끌기, 키보드는 위·아래 화살표. 내가 만든 목록만, 듣는 중에 옮겨도 듣던 곡을 따라간다) |
| 8 | 섞어 듣기와 한 곡 반복 | 매번 같은 순서가 지겨울 때 바꿔 들을 수 있다. | 어려움 | ✅ 넣었다 (목록마다 단추 두 개. 섞어 듣기는 한 곡씩 모두 한 번만, 한 곡 반복은 곡이 끝나면 같은 곡을 다시. 켜 둔 상태는 저장하지 않는다) |

## 내 아이디어
- "다른 사람들도 내 플레이리스트가 보이긴 하나 수정과 삭제를 못해."
- 상태: ✅ 넣었다 (로그인과 Firestore 로 진짜로 지킨다)
  - 누구나 플레이리스트를 볼 수 있다. 만든 사람(로그인한 본인)만 이름 바꾸기, 곡 넣고 빼기, 순서 바꾸기, 지우기를 할 수 있다.
  - 누가 만든 것인지는 만든 사람의 고유 번호(uid)로 구분한다. 화면에서 막을 뿐 아니라 firestore.rules 가 서버에서도 막는다.
  - 별점은 로그인한 누구나 줄 수 있고, 한 사람이 한 플레이리스트에 하나만 남긴다. (규칙: 별점 칸 안의 "내 칸"만 바꿀 수 있다)

## 로그인과 보관함
- 로그인: Google, 새 창(팝업). 로그아웃 단추 있음. 로그인 전에도 모든 플레이리스트를 보고 들을 수 있다.
- 별명: 처음 로그인할 때 한 번 정한다(바꿀 수 없음). 로그인하면 화면 위쪽에 내 별명을 보여 준다.
- 저장하는 것: 만든 사람 칸에 고유 번호(uid)와 별명. Google 이름과 메일은 저장하지 않는다.
- 로그인하면 생기는 것: 내 별명 표시와 로그아웃 단추, + 칸으로 플레이리스트 만들기, 별점 주기, 내가 만든 것 고치기·지우기. (이 항목은 요청 글에 비어 있어서, 지금까지의 기능을 기준으로 정했다)
- 저장 위치: Firebase 프로젝트 play-list-5f761 의 Firestore. 컬렉션 playlists, profiles.
- 보안 규칙: week-07/firestore.rules (콘솔에는 사용자가 붙여 넣는다). 읽기는 누구나(별명 기록은 나만), 쓰기는 로그인한 사람만, 지우기는 자기 것만.
- 이 기기에 예전에 저장하던 기록은 처음 로그인해 별명을 정하면 내 계정으로 한 번 옮기고 지운다.
- 실패하면 화면 위쪽에 오류 글을 보여 준다.
- Firebase 이름표(firebaseConfig)는 공개해도 되는 값이라 index.html 에 넣었다. (루트 CLAUDE.md 의 "API 키를 파일에 적지 마" 에 해당하지 않는다고 사용자가 말했다.)
- 로그인 주소를 쓰려면 Firebase 콘솔에서: Google 로그인 켜기, 승인된 도메인에 namhh0122.github.io 추가, Firestore 데이터베이스 만들기, 규칙 붙여 넣기.
