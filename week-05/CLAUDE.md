# week-05 · 내 게임 업그레이드

## 주제
- 내 게임 업그레이드

## 이번 주 목표
- 남이 해 봐도 재밌는 게임으로 다듬기

## 만들 것
- 내 게임: week-05/index.html (week-04 내 게임을 복사해 와서 이어 만든다)

## 이번 주 규칙
- 게임은 HTML 과 JavaScript 로 만들고, index.html 을 두 번 눌러도 열리게 한다.
- 그림과 소리는 그 게임 폴더 안의 assets 폴더에 둔다.
- 출처 표기가 필요한 에셋은 그 게임 폴더의 CREDITS.md 에 적는다.
- 답은 한국어로 한다.
- 게임을 바꾸면 확인 도구를 돌려서 화면까지 확인하고, 확인한 것과 확인하지 못한 것을 나눠서 알려 준다.
- 확인 도구는 week-05/check 폴더에 파일로 남겨서 다음에도 다시 쓴다.
- 확인 도구가 찍은 사진과 브라우저 임시 폴더는 커밋하지 않는다.
- 재료에 없는 그림(아이템 · 캐릭터 · 아이콘)이나 소리가 필요하면 이모지 · 도형 · 색 바꾸기로 지어 넣지 말고, 먼저 알려 준다. (깜빡임 · 흔들림 · 번쩍임 같은 효과는 괜찮다.)
